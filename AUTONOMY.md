# Автономность: как пакет развивается без обращения в чат

Коротко: **механику автоматизируем, медицинское содержание — через проверку.**
Движок расшифровки анализов **никогда не ходит в сеть** — твои данные остаются
локально. Обучение идёт на том, что ты в него загружаешь.

## Четыре слоя

1. **Overlay** (`references/user_overrides.json`). Всё выученное пишется сюда;
   базовый `reference_ranges.json` не трогается, поэтому его можно обновлять.
   Движок автоматически сливает overlay поверх базового.

2. **Лог обучения** (`learned/unmatched.log`). Запускай движок с `--learn` —
   всё нераспознанное копится в лог:
   ```bash
   python3 engine/interpret.py blank.txt --learn
   ```

3. **learn.py** — разбирает лог офлайн, fuzzy-сопоставляет с известными
   показателями, добавляет синонимы в overlay **с self-test как воротами**:
   ```bash
   python3 learn/learn.py review     # показать нераспознанное + подсказки
   python3 learn/learn.py auto       # автодобавить уверенные совпадения (≥0.88)
   python3 learn/learn.py apply creatinine="Креатенин"   # вручную
   ```
   Опечатки и синонимы известных показателей добавляются сами; реально новые
   показатели остаются на ручной разбор (движок их не выдумывает).

4. **update.py** — обновление базового справочника (единственное место с сетью,
   запускается вручную/по задаче), тоже через self-test:
   ```bash
   python3 update/update.py --check              # прогнать тесты
   python3 update/update.py --from-file new.json # применить проверенную версию
   python3 update/update.py --from-url <URL>     # скачать и применить
   python3 update/update.py --git                # git pull (если это git-репо)
   ```
   Любое обновление откатывается, если self-test не прошёл или аналитов резко
   стало меньше.

## Что делает «живым без чата» — запланированная задача в AI-ассистенте

Настрой в своём AI-ассистенте повторяющуюся задачу (раз в неделю). Она сама
разберёт накопленный лог. Готовый промпт:

```
Ты сопровождаешь пакет lab-interpreter в этой рабочей папке. Выполни цикл обучения:

1. Прогони: python3 learn/learn.py review — посмотри, что движок не распознал
   за неделю.
2. Для явных опечаток и синонимов уже существующих показателей (сходство высокое)
   запусти: python3 learn/learn.py auto — он добавит их в overlay и сам прогонит
   self-test.
3. Для записей, которые auto оставил на ручной разбор, реши своим суждением:
   - это синоним существующего показателя (посмотри его ключ в
     references/reference_ranges.json)? Тогда добавь:
     python3 learn/learn.py apply <ключ>="<название из лога>"
   - это реально НОВЫЙ лабораторный показатель, которого в справочнике нет?
     НЕ придумывай диапазоны молча. Выпиши его отдельно в сводку как
     «кандидат на добавление, требует проверки нормы» — я решу сам.
4. Прогони финально: python3 update/update.py --check — убедись, что всё зелёное.
5. Пришли короткую сводку: что добавлено в overlay, что осталось кандидатами,
   прошёл ли self-test. Ничего не удаляй из базового справочника.

Важно: никаких медицинских диапазонов «на глаз» в базовый справочник. Синонимы и
единицы — да; новые нормы — только через мою проверку.
```

Как подключить: открой пакет в своём AI-ассистенте, скажи «настрой запланированную
задачу с этим промптом раз в неделю». Дальше раз в неделю будешь получать сводку —
и обращаться в чат не придётся.

## Резюме приватности

- Расшифровка анализа (`interpret.py`) — 100% офлайн, детерминированный Python.
- Обучение синонимам/единицам (`learn.py`) — офлайн.
- Сеть — только `update.py` и только когда ты сам её запустил или настроил задачу
  на обновление из доверенного источника.
