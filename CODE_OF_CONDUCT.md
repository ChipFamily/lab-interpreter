# Кодекс поведения

Проект принимает [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
версии 2.1 как кодекс поведения участников.

Коротко: уважение, доброжелательность, конструктивность. Недопустимы
оскорбления, травля, публикация чужих личных данных и иное неэтичное поведение.

О нарушениях можно сообщить сопровождающему репозитория через приватный issue
или GitHub. Все жалобы рассматриваются конфиденциально.

Полный текст и список недопустимого поведения — по ссылке выше.
