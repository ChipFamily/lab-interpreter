# Пример разбора

> Данные **синтетические**, выдуманы для демонстрации. Реальных пациентов здесь нет.

Сценарий: мужчина 40 лет, два забора с интервалом полгода. На первом — несколько
отклонений (печёночные ферменты, липиды, ТТГ, витамин D), затем коррекция образа
жизни и дефицита витамина D. Второй забор показывает, что всё нормализовалось —
и **delta-check** это наглядно подтверждает.

## Вход (второй забор, `v2.txt`)

```
Пол: муж
Возраст: 40
Гемоглобин 145 г/л
Глюкоза 5.0 ммоль/л
Креатинин 93 мкмоль/л
АЛТ 28 ед/л
АСТ 24 ед/л
Холестерин общий 4.8 ммоль/л
HDL 1.3 ммоль/л
LDL 2.6 ммоль/л
Триглицериды 1.2 ммоль/л
ТТГ 2.4 мкМЕ/мл
Витамин D 34 нг/мл
```

## Запуск

```bash
# первый забор — сохраняется в историю пациента
python3 engine/interpret.py v1.txt --patient DEMO --date 2026-05-10

# второй забор — сравнивается с историей, строит динамику и тренд
python3 engine/interpret.py v2.txt --patient DEMO --date 2026-11-10
```

## Что здесь видно

- **Статичный срез** второго забора — «всё в норме», не очень информативно.
- **Delta-check** превращает это в историю: все прежние отклонения ушли в норму
  (смена статуса `выше→норма` / `ниже→норма`), и каждое изменение **превышает
  порог значимости RCV** — то есть это реальный сдвиг, а не шум.
- **Таблица тренда** со спарклайнами (`█▁`, `▁█`) показывает направление одним
  взглядом: ферменты и липиды вниз, витамин D и гемоглобин вверх.
- **Производные формулы** (СКФ, TyG, де Ритис, индекс атерогенности) считаются
  автоматически из тех же данных.

Именно это отличает инструмент от «снимка одного дня»: тренд виден там, где
отдельное значение его скрывает.
